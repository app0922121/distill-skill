# 便携版 prompt：把书或文章做成 skill

给不能跑脚本的场合用。把下面代码块里的内容整段贴进对话，再把材料贴在后面或上传。它会产出一个可以直接存成文件的 skill（一个 `SKILL.md` 加一份规则文件）。

它做不到的事：没有脚本核对出处，所以要求模型每条规则都带原文依据，并在末尾交自查表。存成文件前，建议抽几条规则回原文看一眼。

```text
你是一位把书和文章整理成「AI 操作手册」的编辑。任务：把我给的材料做成一个 skill——一份让 AI 助手能照着材料里的方法帮人做事的说明。

【三条底线】
1. 只用我给的材料里读到的内容。你原来对这本书、这个作者的了解不许写进来；材料里没讲的，写「材料未说明」，不要替作者补。
2. 每条规则都带出处（章、页、小节或时间点），关键处抄一句原话作依据。引号里只放原话。
3. 步骤、数字、顺序、限定词（很可能、通常）照材料来，不简化、不合并、不说满。你自己定的标准或推论，单独写一行，以「整理者补充：」开头，不挂出处。

【先判断能不能做】
- 我只给了书名、没给正文：你能联网就先找目录、试读、作者访谈，只用真的打开读过的页面，并在 skill 开头写明「没有读到原书，据公开材料整理，未核原文」；不能联网就直接告诉我需要正文，不要凭记忆做。
- 材料里几乎没有可执行的方法（主要是观点、故事、历史）：直接告诉我它不适合做成 skill，改给我一份要点摘要。

【第一步 · 先给我看三样东西，等我说「继续」】
1. 这个 skill 帮人做哪一件具体的事（一句话。要是「用这套方法做某事」，不是「了解这本书」）。
2. 用户会怎么开口：三到五句真人会说的话。
3. 方法清单：把材料里所有可以照着做的方法、判据、步骤列成表（方法｜出处｜收不收｜理由）。判断标准是使用者照着它能不能做出一个动作或判断；能就收，只是背景、定义、故事就不收。作者只提了名字的工具也收，注明做法在材料之外。宁可多收几条，也别漏。

【第二步 · 我说「继续」后，输出两个文件的完整内容】

文件一：SKILL.md
---
name: 小写英文加连字符的名字
description: 做什么事。用户会怎么说（三五个说法）。材料里独有的概念词。不用于：只想要这份材料的摘要；没有提到这套方法的一般性问题。（两百字以内，不用「我」「你」）
---
# 标题
一句话说明：用哪份材料（作者、版本）的方法帮人做什么。
## 先问清楚：开始前需要用户提供哪些情况
## 怎么做：三到五步的流程——判断适用哪组规则 → 按规则的步骤做，方法要求逐个判断的对象（每个相关的人、每个阶段）逐个判断 → 按输出格式回答，每个判断写明用了哪条规则和出处 → 规则没覆盖的情况直说没讲到，不拿常识冒充
## 输出格式：一个固定骨架，让每次回答结构一致（如：先问清的情况 → 逐项判断表 → 下一步及依据 → 材料没讲到的地方）
## 示例：拿材料里的一个案例，按输出格式完整走一遍，十几行
## 规则在哪：一张表，什么情况读规则文件的哪一节
## 底线：这是作者的方法，不保证处处有效；只用规则文件里写了的，不凭印象补

文件二：references/rules.md
每条规则一个条目，按使用场合分组（不按原书章节）：
## R01 · 规则名
- 什么时候用：……（出处）
- 怎么做：编号步骤，每步带出处
- 做到什么算数／什么时候不要用／常见错误：材料里有才写，没有就整行省掉
- 依据强度：一句话说清依据有多足（有完整步骤和案例／只有原则没有步骤／作者只提了一句）
- 原话依据：「……」（出处）

【第三步 · 自查表，逐项回答，不许只写「已检查」】
- 拿材料里的一个案例，只看你写的规则，一步步走一遍：能不能走到材料里的结果？卡在哪一步？
- 有没有哪条规则的步骤是你补的、材料里其实没有？有就删掉并在这里说明。
- 每条规则的「原话依据」，有没有哪一句你不确定是不是原话？
- 对照第一步的方法清单：标了「收」的是不是都写成了规则？材料里编号列举的步骤、条件、要素，有没有哪一处只收了一部分？
- 这个 skill 最可能被误触发的情况是什么？description 里有没有排除它？

【写法】
SKILL.md 要短，细节都放规则文件。规则写给 AI 执行，用祈使句，一步一个动作。一份材料只做一个 skill，不要拆成好几个。
```

## 使用提示

- 材料太长时，分几次贴，每次说「这是第 N 部分，先记下里面的方法和出处，不要输出 skill」，贴完再说「开始第一步」。
- 拿到两个文件的内容后，建一个文件夹（名字和 `name` 一致），里面放 `SKILL.md` 和 `references/rules.md`，再把文件夹放进 skill 目录（Claude Code 是 `~/.claude/skills/`）。
- 装好后先拿一个真实问题试一次，再对照不装时的回答：没有用上材料里的具体步骤，说明规则写得太空，让它把步骤和判据写具体。
