# 02 · 全书地图、分批抽底稿、逐字稿、多份材料

第 1、2 步读这份。

## 1 全书地图（先看全貌，再读细节）

**怎么读**：目录、序言或前言、结语或最后一章通读；其余每章读开头和结尾各一小段，看它想说什么、落在哪。这一步不求细，求的是知道全书的骨架，以及作者自己怎么概括这本书。

**写 `W/map.md`**，包含：

1. **材料状况**：版本、总页数或字数、抽取质量问题、材料等级。
2. **这是什么类型的内容**（可以混合）：方法与实操／论述与观点／叙事与案例／知识与参考／课程与讲座／对话与访谈。类型决定后面抽什么、成品怎么搭。
3. **一句话主旨**：必须引作者自己的主旨句，带锚。作者没有明说的，写自己的概括并标 `【归纳】`。
4. **作者要解决什么问题、给谁看**。带锚。
5. **各部分怎么连起来**：哪几章是主干，哪几章是铺垫或展开，章与章之间是并列、递进还是先问题后解法。
6. **章节表**：每章一句话说它讲什么。
7. **关键术语初表**：作者自创或有特别用法的词，先记名字，定义在抽取时补。
8. **用途**：用户读这本书想解决什么。没说就按「通读理解」处理。

**写 `W/chapters.json`**（脚本据此排批次、查覆盖）：

```json
[
  {"id": "ch01", "title": "序言", "source": "S1", "start_line": 1, "end_line": 180, "class": "support"},
  {"id": "ch02", "title": "第一章 ……", "source": "S1", "start_line": 181, "end_line": 960, "class": "core"},
  {"id": "ch14", "title": "致谢", "source": "S1", "start_line": 9200, "end_line": 9260, "class": "skip", "reason": "致谢，无正文内容"}
]
```

- `start_line`、`end_line` 是 `W/text/<ID>.txt` 里的行号。先看 `W/text/<ID>.headings.json` 里脚本找到的疑似标题行，再回原文确认；脚本只是提示，可能漏、可能多，以读到的为准。
- 章节要把整份文本铺满，中间不留空档。不要的部分也要列出来，标 `skip` 并写 `reason`。
- `class`：`core` 承载主旨和主要论点的章；`support` 铺垫、补充、案例集；`skip` 版权页、推荐语、致谢、广告、索引、参考文献、与主题无关的附录。
- 拿不准是 core 还是 support 时标 core。
- 章内再分节不必写进来；一章超过 4 万字脚本会自动切成几批。

然后排批次：

```bash
python3 S/prep.py plan W          # 输出每批读哪个文件的哪些行
```

## 2 分批抽底稿

每一批读 `plan` 给的行号范围，写一个文件 `W/notes/<批次>.md`。

### 2.1 派子代理时的任务书（逐条都要给到）

- 先读 `W/map.md`，知道全书在讲什么、这一批在全书的位置。
- 只读 `W/text/<ID>.txt` 的第 X 到第 Y 行，**从头读到尾**，不跳读、不抽样。
- 按下面 2.2 的格式和 2.3 的必抽项，把底稿写进 `W/notes/<批次>.md`。
- 只写这次读到的。对这本书原有的印象不许写进底稿。
- 文件末尾写「和地图不一样的地方」。
- 写完只回一行：文件路径、条目数、读到的最后一行行号。

没有子代理时，自己按批次顺序做，每做完一批先存盘再做下一批。

### 2.2 底稿条目格式

```markdown
### N-ch03-07 · 方法步骤
> 没有诊断就开处方，在医学上叫渎职，在销售上叫推销。 〔p45〕
述：先诊断再给方案；作者把跳过诊断直接推产品称为推销。
```

- 编号 `N-<章节id>-<序号>`。
- 引用块里是**逐字抄的原话**，中间要省略就用 `……`。句末挂锚。脚本会逐字去原文里找，位置也会查。
- `述：` 是自己的转述，只转述这段原话的意思，不加外面的东西。
- 原话太长（超过一百字）就只抄最关键的一两句，其余写进转述，转述句末也挂锚。
- 一条底稿里要抄两三句不相连的原话时，每句单独一行、各自以锚收尾（或中间空一个 `>` 行）。脚本按「以锚收尾的一行」算一条引文；几句连着写、最后才挂一个锚，会被当成一整句去找，找不到。
- 跨页的句子可以照常抄，页眉和页码行脚本会跳过。
- 看不清、拿不准的地方在行尾标 `〔存疑：原因〕`，例如 OCR 错字、专名拼写、图表读不到。

锚的写法：`〔p45〕` 第 45 页；`〔p45-47〕`；`〔c3〕` EPUB 第 3 个正文文件；`〔t12:34〕` 时间点；`〔L120〕` 行号；有多份材料时加来源前缀 `〔S2:p45〕`、`〔W03:L15〕`。

### 2.3 每类内容必须记下什么

一本书里通常几类都有，按段落实际是什么来记，不要整本只套一类。

| 单元类型 | 必须记下 |
|---|---|
| 主张 | 作者的原话；它针对什么问题；作者自己给的限定条件 |
| 论证 | 理由是什么；用了什么证据；从证据到结论中间靠什么连起来 |
| 方法步骤 | 每一步做什么、顺序、做到什么算完成；作者说的前提和适用场合 |
| 判据与阈值 | 具体的数字、信号、分界线，照抄，不四舍五入 |
| 清单与名目 | 作者编号或逐条列举的东西（几条原则、几个要素、几条好处、几个标志）：记下一共几条，每条的名字和一句话意思，一条不少。成品里它们要全部列出 |
| 图表与模型 | 有哪些组成部分、各叫什么、彼此怎么对应；读不全的写明读到了哪些 |
| 案例 | 谁、遇到什么、怎么做的、结果如何；它用来说明哪条主张 |
| 数据 | 数字、单位、年份、作者给的来源 |
| 术语 | 作者的定义原话；和日常意思有什么不同 |
| 反例与边界 | 作者说在什么情况下不适用、会失败、要小心 |
| 作者回应的反对意见 | 反对意见是什么，作者怎么答 |
| 金句 | 少而精；只抄真的被作者当作结论说出来的话。成品里放在它所支持的那个论点下面，不单设板块 |

### 2.4 抽取时的纪律

- **先抄原话，再写转述。** 顺序不能反：先钉住证据，转述才不会跑。
- **专名、数字、年份照抄。** 不改写、不换算。
- **图表**：文本里只剩图注或一堆散乱数字时，标 `〔存疑：图表未读到〕`；这张图对论点很关键时，有 PDF 就用 `pdftoppm -f N -l N -png` 把那一页转成图片再看。手里只有文本、看不到原图时，底稿只记正文里明确说到的部分；从散字里拼出来的结构是你的猜读，底稿里单列一条并写明「猜读」，成品里只能进评注。
- **限定词照录**：「通常」「几乎」「恐怕」「如果……就」这类词是作者意思的一部分，转述时带上。
- **书里说的不等于事实。** 底稿只记「作者这么说」，不替作者担保它在现实中成立。
- **脚注、尾注**里有实质内容（限定条件、数据来源）的要记。
- **「和地图不一样的地方」**：每批末尾写——这一批里有什么是地图没预料到的、和地图说法矛盾的、比预想更重要或更不重要的。没有就写「无」。全部批次做完后，据此修订 `map.md` 和章节分类。这一步是为了不让先入为主的地图把后面的阅读框死。

## 3 逐字稿与字幕

- 定位用时间点 `〔t12:34〕`。纯文本逐字稿没有时间标记的，用行号。
- **引文从原始转写里抄**，不要先「润色」再抄。口头禅、重复可以在转述里省掉，但引用块里要么照抄，要么不引。
- 自动转写会把专名、术语、数字听错。拿不准的标 `〔存疑：转写〕`，能从上下文、幻灯片或视频简介确认的就确认。
- 多人对话要记是谁说的。分不清说话人时写明「说话人不明」。
- 口语内容常常绕回来讲同一件事。同一观点在几处出现的，合成一条底稿，把几个时间点都挂上。
- 课程、讲座按「讲」或话题切章节；没有明显分段的长对话，按话题转换处切。
- 现场演示、板书、幻灯片里的内容，转写稿里没有的，标 `〔存疑：画面内容未读到〕`。

## 4 多份材料

1. 每份材料各自登记（S1、S2……），各自建地图和底稿。底稿编号加来源前缀：`N-S2-ch03-07`。锚一律带来源前缀。
2. 全部底稿完成后写 `W/cross.md`，按**话题**（不按材料）对照：

   | 话题 | S1 怎么说 | S2 怎么说 | 关系 |
   |---|---|---|---|
   | …… | ……〔S1:p30〕 | ……〔S2:t08:10〕 | 一致／互补／冲突／只有一方谈到 |

3. **冲突并列，不调和。** 两份材料说法不同，就两边都写出来，各挂各的锚。谁对谁错，要说也只能写进评注块。
4. 同一个词在不同材料里意思不同的，在术语表里分开列，不合并。
5. 成品按话题组织，每个论点写清出自哪份材料。只有一份材料支持的，不写成「几份材料都认为」。
